# M0 원문 대조 기록

- 대조일: 2026-11-17(2026-11-18 추가 대조: 입찰무효 근거, 지방계약 협상적격 기준)
- 출처: 법제처 국가법령정보센터(law.go.kr) 현행 행정규칙·법령 본문과 별표·별지 PDF
- 대상: 프로필 `national_negotiation_sw`의 제도 수치(설계서 부록 A)
- 판정: 원문과 같으면 `verified`, 원문이 없거나 법령 밖(공고·이용안내) 근거면 `provisional`으로 둔다

## 대조하다 새로 찾은 의무(기능 후보)

- **조견표 등록**(조달청 세부기준 제6조의2③): 입찰자는 제출기한까지 "제안서의 목차 및 평가항목별 해당 쪽수가 명기된 조견표"를 시스템에 등록해야 한다. 목차·평가항목·렌더 쪽수를 이미 알고 있으므로 자동으로 만들 수 있다.
- **정량 제안서 별도 파일**(같은 조④): 정량평가 분야 제안서는 정성평가 분야와 별도 파일로 낸다. 별지 묶음(`04_정량제안서.pdf`)이 이미 이렇게 나뉜다.
- **PM 직접 발표**(행안부 지침 제20조): 발표를 하는 사업은 사업관리자(PM)가 직접 발표하도록 제안요청서에 명시해야 한다. 발표 대본·점검표에 반영할 수 있다.
- **비방 관련 서약서·확인서**(조달청 세부기준 별지 제21·22호): 비방 평가를 하는 공고에서는 제안서와 함께 낸다. 별지 채우기 대상에 넣을 수 있다.
- **SW 평가기준 가점**(제4조④): 기술자료 임치, SP 품질인증, 상생협력계획, 표준하도급계약서 활용 등은 총점 밖 5점 이내 가점이다. 회사 KB 인증 항목과 연결할 수 있다.

## 지방계약(지자체 프로필용) — 2026-11-18 대조

국가 협상계약 프로필(`national_negotiation_sw`) 밖이지만, 지자체 프로필(M4)을 만들 때 쓸 값을 원문으로 확인했다.

| 항목 | 값 | 원문 근거 |
|---|---|---|
| 협상적격 기준(일반) | 기술능력·가격 합산 70점 이상 | 지방 낙찰자 결정기준 제7장 5.가 |
| 협상적격 기준(소프트웨어 사업) | 기술능력 평가점수가 기술능력 평가분야 배점한도의 85% 이상 | 같은 곳: 「소프트웨어진흥법」 제2조제3호 SW, 「국가정보화기본법」 정보화 사업, 「전자정부법」 정보시스템 사업. 계약특성상 필요하면 대상점수를 조정할 수 있고 공고에 미리 알린다 |
| 가격 초과 제외 | 입찰가격이 추정가격+부가세(예정가격) 초과 시 협상적격자에서 제외 | 같은 곳 5.나 |
| 평가항목·배점(별표 1, 용역·물품) | 정량 20, 정성 60, 가격 20 | 같은 장 [별표 1]. 분야별 배점한도는 10점 범위에서 가감 가능(3.다). 가격 평점에서 SW사업은 예정가격의 80% 미만을 80%로 계산 |
| 기술(설계)·가격 제안서 | 구분하여 동시에 제출하게 할 수 있음 | 같은 장 2.나 |

지자체 SW사업의 기술:가격 비율은 행안부 「정보시스템 구축·운영 지침」 제18조(90점)가 행정기관·공공기관 정보화사업에 함께 적용되는지 공고별로 확인한다(별표 1 기본값은 80:20).
